# Linux FHS

우분투를 포함한 리눅스 시스템은 FHS(Filesystem Hierarchy Standard)라는 파일 시스템 계층 표준을 따릅니다. 최고 최상위 디렉터리인 루트(`/`) 아래에는 역할에 따라 엄격하게 분리된 디렉터리들이 위치합니다.

## 주요 디렉터리 상세 설명

* **`/bin` (Binaries)**
* **의미:** 필수 실행 파일(바이너리)
* **설명:** 시스템 부팅 및 복구 시 필요한 기본 명령어(`ls`, `cp`, `mv`, `bash` 등)가 들어있습니다. 최신 우분투에서는 `/usr/bin`으로의 심볼릭 링크로 처리됩니다.


* **`/boot` (Boot)**
* **의미:** 부팅 관련 파일
* **설명:** 리눅스 커널 이미지(`vmlinuz`), 부트로더(GRUB) 설정 파일 등 시스템 부팅에 핵심적인 파일들이 위치합니다.


* **`/dev` (Devices)**
* **의미:** 장치 파일
* **설명:** 리눅스는 "모든 것을 파일로 다룬다"는 원칙을 따릅니다. 하드디스크(`/dev/sda`), 터미널, USB 등 하드웨어 장치를 파일 형태로 추상화해 놓은 공간입니다.


* **`/etc` (Etcetera)**
* **의미:** 시스템 설정 파일
* **설명:** 시스템 전반에 걸친 모든 환경 설정 파일(네트워크, 사용자 계정 설정, 서비스 설정 등)이 저장됩니다. (예: `/etc/passwd`, `/etc/fstab`)


* **`/home` (Home)**
* **의미:** 일반 사용자 홈 디렉터리
* **설명:** 시스템의 일반 사용자들의 개인 저장 공간입니다. 사용자 계정명이 `user1`이라면 `/home/user1` 디렉터리가 생성되어 문서, 다운로드 파일 등을 관리합니다.


* **`/lib`, `/lib64` (Libraries)**
* **의미:** 공유 라이브러리
* **설명:** `/bin`이나 `/sbin`에 있는 실행 파일들이 작동하는 데 필요한 핵심 커널 모듈과 C 라이브러리 파일(`.so`)이 위치합니다. (`/usr/lib`로 링크됨)


* **`/media` (Media)**
* **의미:** 가변 이동식 매체 마운트 지점
* **설명:** USB 메모리, CD-ROM, 외장 하드 등을 연결했을 때 시스템이 자동으로 마운트(연결)해 주는 디렉터리입니다.


* **`/mnt` (Mount)**
* **의미:** 임시 마운트 지점
* **설명:** 관리자가 다른 파일 시스템이나 네트워크 드라이브를 수동으로 임시 마운트할 때 주로 사용하는 디렉터리입니다.


* **`/opt` (Optional)**
* **의미:** 추가 패키지 소프트웨어
* **설명:** 기본 서드파티 응용 프로그램(예: Chrome, Slack, 타사 상용 소프트웨어)이 설치되는 공간입니다.


* **`/proc` (Processes)**
* **의미:** 프로세스 및 커널 가상 파일 시스템
* **설명:** 실제 디스크 용량을 차지하지 않는 가상 파일 시스템입니다. 현재 실행 중인 프로세스 정보와 커널 상태(`cpuinfo`, `meminfo` 등)를 메모리 상에서 실시간으로 보여줍니다.


* **`/root` (Root User Home)**
* **의미:** 최고 관리자(root) 전용 홈 디렉터리
* **설명:** 시스템 최상위 경로인 `/`와는 다릅니다. 관리자 계정인 `root` 사용자의 개인 홈 디렉터리입니다.


* **`/run` (Runtime)**
* **의미:** 실행 중인 시스템 런타임 데이터
* **설명:** 부팅 이후 현재 작동 중인 서비스들의 상태 정보(PID 파일, 소켓 파일 등)가 임시 저장되며, 재부팅 시 초기화됩니다.


* **`/sbin` (System Binaries)**
* **의미:** 시스템 관리자용 실행 파일
* **설명:** `fdisk`, `ifconfig`, `iptables` 등 시스템 관리 및 복구를 위해 `root` 권한이 필요한 실행 파일들이 들어있습니다. (`/usr/sbin`으로 링크됨)


* **`/sys` (System)**
* **의미:** 시스템 하드웨어 및 커널 제어 구조
* **설명:** `/proc`와 유사한 가상 파일 시스템으로, 커널이 인식한 하드웨어 장치와 드라이버 구조를 계층적으로 보여주고 설정을 변경할 수 있게 합니다.


* **`/tmp` (Temporary)**
* **의미:** 임시 파일 저장소
* **설명:** 시스템이나 프로그램이 작동 중에 생성하는 임시 파일들이 저장됩니다. 대부분 재부팅 시 또는 주기적으로 자동 삭제됩니다.


* **`/usr` (User System Resources)**
* **의미:** 사용자 시스템 자원
* **설명:** 일반적인 프로그램, 라이브러리, 문서 등이 설치되는 가장 큰 디렉터리입니다. Windows의 `C:\Program Files`와 유사한 역할을 합니다.
* `/usr/bin`: 대부분의 일반 사용자 명령어
* `/usr/local`: 사용자가 직접 소스 코드를 빌드하여 설치한 프로그램 위치




* **`/var` (Variable)**
* **의미:** 가변 데이터 저장소
* **설명:** 시스템 작동 중 내용이 지속적으로 변경되는 파일들이 저장됩니다.
* `/var/log`: 시스템 및 프로그램 로그 파일
* `/var/mail`: 메일 데이터
* `/var/www`: 웹 서버 파일
