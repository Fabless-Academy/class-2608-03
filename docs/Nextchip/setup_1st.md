### 2.2 FTDI VCP Driver

- [FTDI Virtual Com Port(VCP) Driver](https://ftdichip.com/drivers/vcp-drivers/)
- Board ↔ PC 사이 Serial 통신을 위한 가상 통신 포트
  - 다운로드 받은 설치 패키지 설치
  - 설치 후 USB to Serial 통신 케이블 연결 시 ‘장치관리자’에서 통신 포트 연결 확인

- Session 설정
  - Session - Seral 선택 - 통신 설정 (Serial port :  FTDI VCP 설치 과정 장치관리자에서 확인한 통신포트, Speed : 115200)
