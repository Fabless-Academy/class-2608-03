# `.vimrc` 기본 setting

```plaintext
set nu

set showcmd             " 명령어 표시
set wildmenu            " 명령행 자동완성

" 들여쓰기 및 탭 설정
set autoindent          " 자동 들여쓰기
set smartindent         " 스마트 들여쓰기
set cindent             " C언어 스타일 들여쓰기
set tabstop=4           " 탭 크기
set shiftwidth=4        " 자동 들여쓰기 크기
set expandtab           " 탭을 스페이스로 변환
set smarttab            " 스마트 탭
```
